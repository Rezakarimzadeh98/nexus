# Contributing

NEXUS ships phase-by-phase. The checklist of record is [docs/ROADMAP.md](docs/ROADMAP.md).

## How to help

1. Prefer the **ACTIVE** phase exit criteria over inventing new engines.
2. Open an issue or Discussion before large design changes; add an ADR when crossing engine boundaries.
3. Keep evidence links and provenance intact — never drop source attribution to “simplify.”
4. Do not contribute operational targeting, exploit weaponization, or closed harmful datasets.
5. When UI lands, prefer sanitized screenshots and short GIFs in `docs/assets/` and update the README.

## PR checklist

- [ ] Matches an open roadmap item or issue
- [ ] Docs/README updated if user-visible
- [ ] Tests or fixtures for pipeline behavior when applicable
- [ ] No secrets, private data, or inflated live metrics

Security reports: [SECURITY.md](SECURITY.md).
