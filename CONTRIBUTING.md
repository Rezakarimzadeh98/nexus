# Contributing

NEXUS is built phase-by-phase per [docs/ROADMAP.md](docs/ROADMAP.md).

1. Prefer the **ACTIVE** phase exit criteria over new engines.
2. Open an issue before large design changes; add an ADR when crossing engine boundaries.
3. Keep evidence links and provenance intact — never drop source attribution to “simplify.”
4. Do not contribute operational targeting, exploit weaponization, or closed harmful datasets.

Security reports: see SECURITY.md (added in Phase 0 completion).
