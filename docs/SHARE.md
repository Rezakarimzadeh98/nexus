# Sharing NEXUS

Use this kit when posting to Show HN, Reddit, LinkedIn, X, or newsletters.  
Keep claims honest: Phase status must match [ROADMAP.md](ROADMAP.md). Never invent live metrics.

## Visuals (safe to share)

- `docs/assets/social-preview.png`
- `docs/assets/loop-diagram.png`
- `docs/assets/dashboard-preview.png` (product north star — label as preview until Phase 6)

Do not share `.env`, API keys, private datasets, or non-public customer data.

## One-liner

`NEXUS — universal intelligence engine: living state, signals with evidence, forecasts you can score.`

## Show HN

**Title**

`Show HN: NEXUS – a living intelligence engine (state, signals, evidence, scored forecasts)`

**Post**

> Most “intelligence” stacks are either counting dashboards or chat over documents. Neither keeps a living model of what changed, why, or whether yesterday’s forecast was right.
>
> NEXUS is an open, domain-agnostic engine: observe → understand → connect → detect → discover → forecast → verify → learn. Core concepts stay stable; adapters plug domains (news, finance, cyber, …). LLMs may help extract and explain — they are not the product.
>
> Phase 0 (product + architecture + public repo) is done. Building toward a What Changed dashboard with source-linked evidence, then public benchmarks (lead time, calibration).
>
> https://github.com/Rezakarimzadeh98/nexus

## Reddit / LinkedIn / X

Lead with the human failure: *too much data, no living picture, no scorekeeping.*  
Then the loop image.  
Then one ask: star, Discussion with a domain, or take a roadmap checkbox.

## Update cadence

When a phase exit lands:

1. Tick checkboxes in `ROADMAP.md`
2. Refresh README status badge / phase line
3. Replace preview images with real screenshots/GIFs when the dashboard exists
4. Add a short entry to CHANGELOG (from Phase 1 onward)
